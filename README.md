# Timber Empires docs

The player guide and modding documentation for Timber Empires, a PvP mod for multiplayer Timberborn. Read it at https://fezvrasta.github.io/TimberEmpires-Docs/.

The mod itself isn't open source. This repository holds only its documentation. Report bugs [on Discord](https://discord.com/channels/1556989523756322856/1556990538736074762).

The pages under `reference/` are generated from the mod's files. To preview the site locally: `bundle install && bundle exec jekyll serve`.
